# Pritesh Keshri - Portfolio Website

Welcome to the personal portfolio website of **Pritesh Keshri** — AI/ML Developer & Full Stack Engineer.  
This site showcases my skills, projects, certifications, and achievements in the field of Artificial Intelligence, Machine Learning, and Web Development.

## 🚀 Features

- **Modern Responsive Design**  
  Built with HTML, CSS, and JavaScript for seamless experience across devices.

- **Sections Included:**
  - **Home:** Quick intro, social links, and a call to action.
  - **About:** My background, experience, and resume download.
  - **Skills:** Technical skills in AI, ML, and web development.
  - **Qualification:** Education and work experience timeline.
  - **Certifications:** Visual gallery of my certificates.
  - **Projects:** Swiper-powered carousel of my top projects.
  - **Honors & Awards:** Achievements and recognitions.
  - **Contact:** Email, phone, and LinkedIn for easy reach.
  - **Footer:** Quick links and social profiles.

- **Interactive Elements:**
  - Swiper.js carousels for projects and testimonials.
  - Dark/light theme toggle.
  - Smooth scroll navigation.
  - Downloadable resume.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Libraries:** [Swiper.js](https://swiperjs.com/) for carousels, [Font Awesome](https://fontawesome.com/) for icons
